Overview

Everything you save here updates the live website for every visitor.

How this works

Use the sections on the left to edit each part of the site: page text, services, portfolio projects, awards, contact details, images, and the color theme. Every section has its own Save Changes button. When the status at the bottom of the left menu says Live, a save is stored on the server and every visitor sees it right away, on any device.

Photos and PDFs you upload are stored as separate files, so there is no small browser storage limit to run into. Images are shrunk automatically before upload, so hundreds of them take very little space. PDFs can be up to about 8 MB each. There is no practical limit on how many photos you can add.

Reset everything

Replaces everything on the live site with the original default content and theme. Uploaded files stay stored but are no longer used.
